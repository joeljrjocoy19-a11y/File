# Joel Jr. M. Jocoy — Digital Portfolio

A responsive, futuristic personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — complete portfolio website
- `joel-profile.png` — profile photo used by the page
- `assets/joel-profile.png` — backup photo path

## Publish with GitHub Pages
1. Upload the files in this ZIP to the root of your GitHub repository.
2. Keep `index.html`, `joel-profile.png`, and the `assets` folder together.
3. In your repository, open **Settings → Pages** and enable deployment from the `main` branch and `/ (root)` folder.
4. Wait a few minutes, then refresh your GitHub Pages website.

The page tries `joel-profile.png` first and falls back to `assets/joel-profile.png`.
